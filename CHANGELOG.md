# Changelog

Alle wichtigen Änderungen an Protex werden hier dokumentiert.

## 1.0.0 – 2026-11-09

- Erste Veröffentlichung des Protex Agent Skills.
- Regeln für ehrliche Kommunikation und nachvollziehbare Testergebnisse ergänzt.
- Explizite Freigabe vor Löschen, Verschieben, Umbenennen und destruktivem Überschreiben verankert.
- Strikte Begrenzung auf den vom Nutzer freigegebenen Änderungsumfang festgelegt.
- Ablauf für Projektprüfung, minimale Änderungen, Diff-Kontrolle und Tests definiert.
- Referenzen für Dateioperationen und Testberichte ergänzt.
- Validator, Unit-Tests und GitHub Actions Workflow hinzugefügt.
